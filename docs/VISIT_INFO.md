# 景点实用信息与攻略入口

## 使用与边界

刷新任意已有行程页即可使用，无需重新规划。景点卡片显示门票预算估算、开放时间来源、查询时间、官方入口和攻略搜索。
仅增强结果页：不会调整闭馆日期冲突、改写预算、查询余票或执行预约。0 元估算不是已确认免费。
现有高德 Key 仍受其权限、配额与收费规则约束；未增加付费服务或模型调用。

## 接口与数据口径

登录保护的 `GET /api/poi/visit-info`：
- 必填 `name`、`city`；可选 `poi_id`、成对经纬度、ISO `visit_date`。
- 有 ID 使用高德 v5 地点详情 `show_fields=business`；无 ID 的历史记录先用城市、名称、坐标获得唯一地点，再查询详情。
- 复用照片服务的严格匹配规则：名称、城市一致，有坐标时距离不超过 500 米。拒绝同名异地、检票处等子地点。
- 状态为 available / no_data / unmatched / permission_denied / timeout / unavailable；返回 match_status、opening、source_name、source_url、fetched_at、official、notice。
- `opening.today` 仅适用于查询的北京时间日期；不同游玩日期不返回此值。`opening.regular` 是原始常规安排，不自动解析节假日或做未来开放承诺。
- 查询时间不是上游更新时间。上游更新时间未知，接口返回 null。官方人工核验日期来自登记表，不随刷新变化。
- 不读取 `business.cost` 作为票价，不返回实时票种或库存。
- 高德请求超时 8 秒、无重试，复用进程内限速。成功/无数据/未匹配结果缓存 15 分钟，最多 512 条，并在北京时间跨日时失效；故障不缓存。
- 前端按城市、地点、坐标、游玩日期去重，跨重载最多 3 个并发；忽略编辑、切换或卸载后的过期响应。
- 这些数据不写入 TripPlan、模型提示、历史记录或检查点，不需要数据库迁移。
- 日志事件：`poi.visit_info_resolved`（visit_status、cache_hit、elapsed_ms）、`poi.visit_info_failed`（仅 error_type）。不输出含密钥的请求地址。

## 维护官方来源表

登记表位于 `backend/app/services/official_visit_sources.json`；不复用原有估算价格表作为官方事实。

增加或更新景点：
1. 从景区/主管单位官网确认身份、参观说明和票务页面，不以搜索摘要、第三方攻略或模型猜测作依据。
2. 在高德确认景点的唯一 ID；填写 city、精确 names（仅经人工确认的别名）和 poi_ids。不要把入口、售票处的 ID 加入主景点。
3. 填写 source_name、实际核验当天的 verified_at、简短 reservation_note，以及链接的 purpose（reservation / price）、label、url。
4. 若仅支持小程序，保留官网预约说明链接，在说明中写清官方小程序名称；不要拼接未经确认的支付/预约深链。
5. 新官方域名同步加入服务中的 ALLOWED_OFFICIAL_HOSTS。只允许 HTTP/HTTPS，无用户名密码，不进行后台任意网址抓取。
6. 重启后端清除登记表内存缓存，运行后端来源测试，再用浏览器打开链接核验后提交 Git。
7. 链接失效或身份无法确认时删除对应条目/链接，不把核验日期改成今天来伪装已复核。未知景点显示“暂无已核验官方入口”。

首批：故宫博物院、颐和园、天坛公园。非这三个景点仍可获取高德参考开放时间和攻略搜索。

已检查的官方来源：

- https://summerpalace.net.cn/index.html （官方开放安排及票务信息；也由天坛官网友情链接确认其身份）
- https://www.tiantanpark.cn/index.html （官方导览与购票入口）

## 攻略入口

关键词固定为“城市＋景点名称＋游玩攻略”，使用 URLSearchParams 编码。
- 小红书：2026-09-06 浏览器验证搜索页标题、地址和搜索框均正确带入关键词，使用官网搜索地址。
- 大众点评：官网搜索在本次环境中无法验证，使用明确标注的百度 `site:dianping.com` 站外搜索。浏览器实测出现百度验证码，未自动处理；不保证免登录/免验证。
- 所有景点始终提供复制搜索词、可手动选择的文字及平台官网链接。剪贴板不可用时显示手动复制提示。
- 不抓取、存储或审核第三方笔记/评论。外链新标签页开启，使用 noopener noreferrer，拒绝非 HTTP/HTTPS 和嵌入账号密码的链接。
