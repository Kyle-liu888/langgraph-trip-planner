# 景点照片：高德地点匹配

## 行为

- 前端行程展示不再请求 Unsplash，不采用历史记录或模型输出里的 `image_url` 作为兜底。
- `GET /api/poi/photo` 接收 `name`、`city`、可选 `poi_id`、`longitude`、`latitude`。
- 有 ID：调用现有高德 v3 `/place/detail`，`extensions=all`，验证返回 ID、名称及城市；有完整坐标时还要求距离不超过 500 米。
- 没有 ID：必须提供城市和完整坐标，按名称在指定城市搜索；要求名称、城市匹配且距离不超过 500 米，只有一个匹配地点才展示照片。
- 名称仅规范空白和中英文括号；城市兼容末尾“市”。不模糊匹配别名，不将检票处、入口或游乐场当作同一景点。
- 已有 ID 但核对失败时，不偷偷改用其他地点。严格匹配可能少展示一些照片，但不会为了填满页面而选择不确定的配图。
- 返回 `available` / `no_photo` / `unmatched` / `unavailable`，分别表示可用、无照片、匹配不确定、查询故障。可用照片标注“图片来源：高德地图”。图片链接加载失败同样显示明确提示。

## 性能及边界

- 图片在行程生成后独立加载，不调用大模型，不阻塞地图初始化，不修改行程或检查点。
- 前端按城市、ID、名称、坐标去重，最多 3 个并发请求，单请求客户端超时 15 秒；卸载页面后不继续排队请求或更新状态。
- 后端使用高德进程内共享限速；照片 HTTP 请求超时配置为 8 秒，不重试。已完成查询结果在进程内缓存 5 分钟，最多 512 条，不落盘保存图片。
- API Key 仅留在后端；异常日志不输出带 Key 的请求地址。日志事件为 `poi.photo_resolved`（含 `photo_status`）及 `poi.photo_unavailable`。
- 图片 URL 仅允许 HTTP/HTTPS。未增加图片代理、批量下载、付费平台、默认图库或人工素材；未来如补充人工图库，应先确认素材使用许可。
- POI 照片是地点关联照片，不保证每张都是全景或最佳封面。接口权限、额度及展示/导出使用要求仍遵循高德平台规则。

## 本次验证（2026-09-06）

- 使用当前配置分别搜索昆明翠湖公园、北京故宫博物院，均成功返回 3 张照片。
- 使用新服务分别按两者真实 POI ID 获取详情，均返回 `available`；首图 HEAD 请求均 HTTP 200、`image/jpeg`。未调用大模型。
- 自动化测试使用模拟地点及 HTTP 响应，覆盖 ID/城市/名称/坐标不匹配、歧义地点、无照片、非法链接、超时、缓存、并发限制、卸载及故障占位。

## 使用

更新后端并刷新已有行程页即可重新加载照片，不需要重新生成行程。旧行程缺少可靠位置时会显示“暂无景点图片（未确认地点匹配）”，不会自动改写历史数据。

官方接口文档：https://lbs.amap.com/api/webservice/guide/api/search/
