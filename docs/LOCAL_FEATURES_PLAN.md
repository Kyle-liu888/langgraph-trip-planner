# 本地功能版实施范围

本轮只实现日志、SSE 节点进度、账号与持久化历史/恢复，不涉及服务器采购、部署、域名、作品集首页或付费服务。

## 1. 日志和节点事件

- 控制台与轮转日志文件输出，统一 request_id / trip_id / run_id。
- 记录节点、实际模型调用、耗时、Token（供应商返回时）、重试及安全错误摘要。
- 不记录密钥、Token、完整 Prompt、用户输入或模型原文。
- 区分正常完成、兜底完成、失败、中断。

## 2. 后台任务和 SSE

- 提交后立即返回任务标识；后台任务独立于浏览器连接。
- 订阅当前 LangGraph 节点、候选轮次和运行事件，心跳与断线重放。
- 刷新页面重新连接已有任务，不能重复创建模型调用。

## 3. 账号、历史与恢复

- 登录后显示账号、新建行程、历史列表、打开、重命名、删除。
- 结果和用户编辑保存到服务端，替换 sessionStorage 作为唯一数据源。
- Checkpointer 保存图执行状态，业务表保存历史与最终结果。
- 重启后显示中断，通过同一 thread_id 手动恢复；不自动触发计费调用。
- 认证与数据库按用户确认沿用 Supabase Free：邮箱密码 + GitHub OAuth。SQLite 仅为离线自动化测试适配器，不是生产配置。

## 验收

- 使用 fake 模型测试，不消耗真实 API 额度。
- 覆盖日志脱敏、事件顺序、断线重连、进程重启后的恢复、账号隔离与历史管理。
- 后端测试和前端构建通过；外部账号配置未提供时须明确说明实测边界。
